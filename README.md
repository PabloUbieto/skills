# Skills
Mi colección personal de skills para Claude Code

## ¿Qué son las skills?
Instrucciones que guían a Claude Code para realizar tareas concretas de forma profesional.

## Estructura

Skills probadas y verficiadas que funcionan correctamente.

| Skill | Descripción |

| `grill-me` | Te interroga hasta que tu plan no tiene fallos |

| `to-prd` | Convierte una conversación en un documento de requisitos |
