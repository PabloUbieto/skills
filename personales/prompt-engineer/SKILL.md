---
name: prompt-engineer
description: Diseña y mejora prompts para modelos de IA. Úsala cuando quieras optimizar instrucciones para Claude, GPT, Gemini u otros modelos. Analiza el prompt actual, identifica mejoras y genera versiones optimizadas.
---

Analiza el prompt que te proporciono y mejóralo siguiendo estas reglas:

Identifica el objetivo principal del prompt y asegúrate de que las instrucciones sean claras y sin ambigüedad.

Añade contexto necesario para que el modelo entienda exactamente qué se espera de él.

Especifica el formato de salida deseado si no está indicado.

Elimina instrucciones redundantes o contradictorias.

Proporciona la versión mejorada del prompt y explica brevemente qué has cambiado y por qué.

Si el prompt es para un caso de uso específico como código, escritura o análisis, adapta las instrucciones al dominio correspondiente.
