Ayúdame a integrar la API de IA en mi proyecto siguiendo estos pasos:

Pregúntame qué modelo quiero usar: OpenAI, Anthropic Claude o Google Gemini.

Configura el cliente de la API con las credenciales necesarias de forma segura, usando variables de entorno para las claves API. Nunca hardcodees las claves en el código.

Implementa la llamada básica al modelo con manejo de errores robusto incluyendo timeouts, reintentos y mensajes de error claros.

Añade tipado correcto si el proyecto usa TypeScript.

Muestra un ejemplo funcional de una llamada completa con su respuesta.

Si el proyecto ya tiene código existente, intégralo de forma que no rompa nada.

Sigue las mejores prácticas de seguridad en todo momento.
