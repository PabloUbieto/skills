description: Gestiona memoria persistente para tu asistente personal Jarvis. Úsala cuando quieras que tu Jarvis recuerde conversaciones, preferencias y contexto entre sesiones. Sin esto Jarvis empieza desde cero cada vez.
---

Ayúdame a implementar un sistema de memoria persistente para mi Jarvis siguiendo estos pasos:

Pregúntame qué tipo de información necesita recordar Jarvis: conversaciones anteriores, preferencias del usuario, tareas pendientes, contexto de proyectos u otros datos.

Implementa un sistema de almacenamiento adecuado según el caso: archivo JSON para proyectos simples, base de datos SQLite para mayor volumen o base de datos vectorial para búsqueda semántica.

Crea funciones para guardar nueva información, recuperar información relevante y eliminar información obsoleta.

Añade un sistema de resumen automático para comprimir conversaciones largas y no saturar el contexto del modelo.

Implementa búsqueda por relevancia para que Jarvis recupere solo la memoria más útil para cada situación.

Asegúrate de que la memoria se guarda de forma segura y que información sensible está protegida.

Muestra un ejemplo de Jarvis recordando información de una sesión anterior en una nueva conversación.
